Polices, icônes, curseur

  • Système : SpaceMono Nerd Font (Nerd Fonts) — omarchy font set "SpaceMono Nerd Font"
  • Affichage : Anton (Google Fonts, OFL) — fonds, Plymouth, verrouillage
  • Icônes d'apps : Yaru-red dans icons.theme
  • Curseur : Bibata-Modern-Classic (noir), taille 24
  • Clavier Wooting : {{ acc }}
  • Neovim / VS Code : aucun thème existant ne colle ; laisser Omarchy les générer depuis colors.toml

Fenêtres — looknfeel.lua

  • Bordure 3 px ; active #f1e7d6, inactive #121010. Pas de dégradé.
  • Arrondi 0 px. Ombres désactivées.
  • Espaces : 8 px entre fenêtres (gaps_in), 16 px au bord (gaps_out).
  • Opacité : active 0.94, inactive 0.90.
  • Flou : activé, taille 8, 2 passes, vibrance 0 — juste assez pour lire le vermillon derrière.

Animations — ressenti « sec et net »

  • Courbe unique, départ rapide et arrêt doux : bézier 0.16, 1, 0.3, 1.
  • Ouverture : popin 85 %, 220 ms.
  • Fermeture : popin 90 % + fondu, 150 ms (plus rapide qu'à l'ouverture).
  • Changement de bureau : slide, 260 ms. Sur le Koorui : slidevert.
  • Fondus (bordures, opacité) : 180 ms. Aucun rebond.

Démarrage

  • Limine : branding VERMILLON en accent ; fond terminal 121010, texte f1e7d6 ; palette = les 8 couleurs ci-contre ; image boot.png : noir, disque vermillon débordant à droite. Noms exacts des clés à vérifier selon la version de Limine.
  • Plymouth : fond uni {{ wall }}. PNG : logo.png (disque noir + SIGNAL crème, 600 px), entry.png (rectangle noir 300×40), bullet.png (carré crème 8 px), progress_bar.png (noir 2 px). Animation possible : le disque pulse (3 images, opacité 100 → 85 %).
