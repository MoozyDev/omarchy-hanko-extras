Toutes les déclinaisons

La barre du haut passe toute la page en V1 (chevron vers la droite) ou en V2 (même logo tourné de 90° dans le sens des aiguilles d'une montre), et change la couleur du thème.

10a

Les deux orientations

V1 · baseLe chevron pointe vers la droite, comme une invite de commande. Version par défaut : barre, avatars, signature.
V2 · tournée de 90°Le chevron pointe vers le bas. Pour les formats verticaux (écran Koorui, bannière verticale, affiche) ou pour varier en motif.
Règles
  • V2 n'est pas une autre forme : c'est le fichier V1 tourné de 90° exactement (vers la droite). Pas d'autre angle.
  • Une seule orientation par support. Ne mélange pas V1 et V2 côte à côte, sauf dans un motif répété.
  • Compensation optique dans un cadre : V1 décalée de 3 % vers la droite, V2 de 3 % vers le bas (le poids du D tire de l'autre côté).

Version contour

trait intérieur = x / 3 · jamais sous 48 px
07 · Contour crème

09 · Mixte (option)D plein, pièces en contour : état « hors ligne ».
Comment calculer le trait
  1. Mesure le diamètre du cercle (largeur totale du logo en V1, hauteur totale en V2 : c'est le même nombre).
  2. Trait = diamètre × 0,035 (soit x / 3).
  3. Dans VectorCraft, Illustrator ou Figma : remplissage vide, contour de cette épaisseur, aligné à l'intérieur.
  4. Avant d'exporter : vectorise le contour (« Vectoriser le contour » / « Outline stroke »).
