# Fenêtres et animations — à traduire dans ~/.config/hypr/looknfeel.lua

## Fenêtres (identiques pour les 3 thèmes)
- Épaisseur de bordure : 3 px
- Bordure active : #f1e7d6 (crème) — pas de dégradé
- Bordure inactive : #121010 (noir)
- Arrondi : 0 px (angles droits)
- Espace entre fenêtres (gaps_in) : 8 px → 16 px visibles entre deux fenêtres
- Espace au bord de l'écran (gaps_out) : 16 px
- Ombres : désactivées
- Opacité : fenêtre active 0.94, inactive 0.90
- Flou : activé, taille 8, 2 passes, vibrance 0

## Animations — ressenti « sec et net », aucun rebond
- Courbe unique : bézier 0.16, 1, 0.3, 1 (départ rapide, arrêt doux)
- Ouverture de fenêtre : popin 85 %, 220 ms
- Fermeture : popin 90 % + fondu, 150 ms
- Changement de bureau : slide, 260 ms (sur l'écran vertical Koorui : slidevert si réglable par écran)
- Fondus (bordures, opacité, calques) : 180 ms

## Curseur
- Bibata-Modern-Classic, taille 24 (paquet AUR bibata-cursor-theme-bin)
